<h1 align="center">Beacon</h1>

**Beacon** is a Feature Flag and Configuration Management Service built using Go. It allows applications to manage projects, environments, feature flags, and configurations through a REST API.

The main goal of this project is to learn how to build a proper REST API and understand the concepts involved in developing a reliable backend service.

### Core Features

- **Project & Environment Management:** Manage projects and their development, staging, and production environments.
- **Feature Flag Management:** Create, update, retrieve, and delete feature flags.
- **API Key Authentication:** Secure API endpoints using API keys.
- **Rate Limiting:** Limit API requests using Redis.
- **Caching:** Use Redis to cache frequently requested data.
- **Structured Logging:** Maintain organized application and request logs.
- **Graceful Shutdown:** Properly shut down the server without interrupting ongoing requests.
- **OpenAPI Documentation:** Document API endpoints using OpenAPI/Swagger.
- **Health Checks:** Provide health and readiness endpoints.
- **Automated Testing:** Write tests for handlers, business logic, and database interactions.

### Tech Stack

- **Language:** Go
- **Database:** PostgreSQL
- **Caching & Rate Limiting:** Redis
- **API Documentation:** OpenAPI / Swagger
- **Containerization:** Docker & Docker Compose

### Project Objective

The purpose of building Beacon is to get practical experience with Go and backend development. Through this project, I want to learn about REST API design, middleware, database interactions, authentication, caching, testing, and other concepts that are commonly used when building backend services.

This project will also serve as a learning foundation before moving on to more complex backend systems.
